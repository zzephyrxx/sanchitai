# 三尺台 广度功能池（Broad List）

- 版本：v1.0（2026-11-18）
- 用途：面向 v1 之后的版本规划。覆盖**班长、社团负责人、辅导员**等未来身份与**通用场景**，共 36 条。每条含一句话描述 + 价值评级（高/中/低，对目标用户）+ 实现成本（低/中/高）。
- 评级口径：价值=解决真实痛点的程度（依据本次调研中可见的同类手工做法）；成本=在 v1 架构（本地库+台历+人员+模板）上的增量。

## Top10（建议优先排期）

1. **A1 待办提醒中心**——所有台账的"收口器"，直接消灭"TODO 文件夹"痛点（价值高/成本低）。
2. **A3 备份与恢复**——用户有真实多设备同步冲突教训，离线产品的信任底线（高/低）。
3. **A4 数据导出**——学院要表的最后一步，不做导出等于台账白记（高/低）。
4. **A12 志愿时长台账**——发展对象考核硬指标（真实考核含志愿时长项）（高/低）。
5. **A15 打印套件**——签到表/座次表每月都要打印，纸质流程短期不会消失（高/低）。
6. **A2 通知中心**——学院部署的入口，与台历联动形成闭环（高/低）。
7. **E4 组织关系转接追踪**——毕业季真实高频事项（高/低）。
8. **E5 思想汇报收缴跟踪**——每季度固定动作，漏收影响发展进度（高/低）。
9. **E1 积分制台账**——制度已落地（2025 年版方案），台账化是自然延伸（高/中）。
10. **B1 班级座位图 / D2 谈心谈话覆盖管理**——为未来身份复用 v1 底座的两个样板（高/低-中）。
