# 三尺台 v0.3.0 设计规划（通用化底座 · 成员生命周期 · 积分引擎 · 志愿时长 · 深度引导）

> 基线版本：`v0.2.6` → 目标版本：`v0.3.0`
> 设计原则：坚持纯本地离线优先、墨韵 / KONTUR 电子纸双皮肤（直角台账框线、等宽数字、硬投影反馈、零冗余装饰）、可视化交互优先于干瘪表单。

---

## 1. 版本核心目标

将「三尺台」从绑定单一高校院系细则的定制工作台，升级为**面向全国高校、机关、国企、社区及两新基层党支部的通用化离线工作台**，聚焦五大核心交付：

1. **工作台通用化底座与模块工坊**：支部场景预设（5 套）、按需启停扩展模块（隐藏菜单与总览卡片但保留数据）、花名册「核心通用 + 场景字段组 + 自定义扩展字段」分层体系、清除源码中写死的特定院系支部默认名。
2. **成员全生命周期与组织关系转接**：彻底告别「关系转出 = 直接删除」，建立状态机（在册正常 / 转出办理中 / 转入待核查 / 流动党员 / 历史归档），配套单人 4 步转出抽屉、毕业季批量转出工作台、新生/新转入多人核查矩阵与核实函生成、账实相符与防误删拦截。
3. **党员积分与评定引擎化重构**：解耦硬编码的 60+40 分桶，升级为数据驱动多方案引擎（通用百分制 / 高校学生基础+履职制 / 五星党员评定模型 / 纯正向加分制 / 空白自定义），按年度绑定方案快照；新增规则方案工坊、分段色条榜单、考勤/党费/志愿一键草稿联动与「单位配置包（`.sctpreset`）」。
4. **志愿时长台账（新增模块）**：支持顶部 KPI 胶囊、「按活动记录 ⇄ 按成员汇总」双视图、三合一录入（人头芯片勾选与单人微调 + 台历/三会一课一键引入 + 粘贴微信接龙名单自动识人）、全员兼容与核实状态、双 Sheet Excel/打印公示单导出、人员详情展示、积分联动与可选考核折算预览。
5. **首次两段式全屏画册引导 + 全局隐私脱敏双版导出**：前半段 3 步初始化，后半段 10 项核心与隐藏神技翻页画廊（配电子纸示意图与直达体验），常驻顶栏「? 指南」随时重看；全部花名册/转接/志愿/积分导出统一支持「脱敏公示版（默认）⇄ 全量报送版（二次确认）」。

## 2. 数据模型演进（Dexie v8 加法迁移）

严格遵循加法演进，保留 v1~v7 迁移链，新增 **v8**：

### 2.1 `members` 表扩展

- 新增字段：
  - `lifecycle_status?: '在册正常' | '转出办理中' | '转入待核查' | '流出党员' | '流入党员' | '已转出' | '停止发展'`（v8 迁移默认回填 `'在册正常'`）
  - `department?: string`（企事业/机关/社区通用：部门/科室/网格）
  - `job_title?: string`（岗位/职级/职称）
  - `office_location?: string`（办公地点/居住楼栋）
  - `custom_fields?: Record<string, string>`（自定义扩展字段值）
- 新增索引：`lifecycle_status`

### 2.2 新增 `transferRecords` 表（组织关系转接、转入核查与流动台账）

- 索引：`id, member_id, direction, status, initiated_date, identity`
- 核心字段：
  - `direction: 'out' | 'in' | 'float_out' | 'float_in'`
  - `status: '办理中' | '已完成' | '已取消'`
  - `transfer_mode?: '线上系统转接' | '纸质介绍信' | '内部调转'`
  - `target_committee?: string`（接收单位上级党委）
  - `target_branch?: string`（接收具体党支部）
  - `source_org?: string`（转入来源党组织 / 流动去向）
  - `letter_no?: string`（介绍信编号）
  - `fee_paid_until?: string`（党费交至年月 `YYYY-MM`）
  - `archive_dest?: '随人事档案' | '个人自提' | '暂存原单位' | '其他'`
  - `receipt_received?: boolean` / `receipt_date?: string` / `receipt_no?: string`
  - `audit_items?: Record<string, 'ok' | 'missing' | 'doubt' | 'unchecked'>`（转入档案核查三态结果）
  - `audit_notes?: Record<string, string>`
  - `contact_logs?: Array<{ date: string; summary: string }>`（流动党员定期联系记录）

### 2.3 新增 `volunteerActivities` 表（志愿时长台账）

- 索引：`id, date, source, status, event_id, identity`
- 核心字段：
  - `title: string` / `date: string` / `source: '支部内部' | '校院活动' | '社会公益' | '其他'`
  - `default_hours: number` / `status: '已认定' | '待核实'`
  - `event_id?: string`（可选关联台历/三会一课事件）
  - `participants: Array<{ member_id: string; name_snapshot: string; hours: number; role_note?: string }>`
  - `note?: string` / `created_at: string`

### 2.4 `meta` 新增配置键

- `workspace-config`：`Sct.WorkspaceConfig`（支部场景、模块开关、场景字段组开关、自定义字段定义、新手引导完成状态）
- `point-schemes`：`Sct.PointScheme[]`（用户自定义及覆写方案库）
- `point-year-scheme`：`Record<string, string>`（年度 → 方案 ID 绑定）
- `point-year-snapshots`：`Record<string, Sct.PointScheme>`（年度方案快照，保证换年改规则不破坏往年历史成绩）

## 3. UI 与交互规格

### 3.1 视觉一致性约束

- 所有新增组件严格使用 `--sct-page / --sct-container / --sct-border / --sct-soft / --sct-muted / --sct-ink / --sct-accent` 变量；
- 电子纸皮肤（`html[data-preset='crm-frosted-glass']`）下全部新卡片、KPI 胶囊、步骤条、画册卡片、矩阵单元格均保持 `border-radius: 0px`、`1px solid var(--sct-border)` 与硬偏移 hover 阴影；
- 所有表格操作按钮沿用 `.sct-op-btn` 系列，表单 Label 使用 `.sct-field-label` 严禁换行。

### 3.2 模块工坊与侧边栏联动

- `设置 → 工作台模块工坊`：卡片网格展示全部扩展模块（座位图 / 党员积分 / 志愿时长 / 政治生日），开关后实时同步左侧导航菜单（`routeStore` 响应式过滤）与总览页对应卡片；关闭不删除任何数据。
- 支持随时切换支部场景预设及管理花名册自定义字段。

### 3.3 成员生命周期与组织关系转接（`/ledger/members`）

- 顶部 5 枚 KPI 状态胶囊：`在册正常` / `转出办理中（红点）` / `转入待核查（黄点）` / `流动党员` / `历史归档`；
- 在册态保留原有「座位图 / 列表」切换（若模块工坊关闭座位图则直接进入列表）；
- 「关系转出」打开右侧 4 步办理抽屉；另设「毕业季批量转出」弹窗支持多选与一键导出《关系转接登记表》；
- 「转入待核查」默认呈现多人核查矩阵，点击成员打开核查抽屉一键生成《商请核实党员档案材料的函》并一键入册；
- 存在任意历史台账记录的成员禁止物理删除，引导走关系转出或停止发展归档；归档成员支持查看只读「个人历史档案全景卡」或「恢复在册」。

### 3.4 党员积分引擎与 `.sctpreset` 单位配置包（`/ledger/points`）

- 内置 4 套方案 + 空白自定义，顶部展示当前年度绑定方案徽章与公式说明；
- 主表按方案维度动态渲染列 + 行内分段色条微图（Stacked Bar）+ 总分或 ★★★★★ 星级徽章；
- 「规则方案工坊」抽屉支持方案切换/克隆、维度卡片网格管理与细则编辑、一票否决与及格线配置；
- 「一键同步草稿」弹窗扫描本年考勤缺勤、党费欠缴、志愿总时长生成待核实积分建议；
- 支持 `.sctpreset` 单位配置包导入/导出（按需勾选打包：积分方案、花名册自定义字段、材料库模板、支部场景配置）。

### 3.5 志愿时长台账（`/ledger/volunteer`）

- 顶部 KPI 胶囊 + 「按活动记录 ⇄ 按成员汇总」切换；
- 新建/编辑抽屉三合一：人头芯片快速勾选与单人微调 + 从台历/三会一课一键引入 + 粘贴微信接龙名单自动匹配姓名；
- 按成员汇总支持可视化进度条与可选「考核折算预览」工具栏；
- 支持双 Sheet Excel 导出、电子纸打印公示单、人员详情抽屉集成展示。

### 3.6 首次两段式全屏画册引导 & 全局隐私脱敏导出

- 两段式全屏画册（`OnboardingGuideModal`）：前半段 3 步初始化，后半段 10 项核心与隐藏功能翻页画廊（含电子纸动态示意图 + 快捷键徽章 + 「立即体验此功能」跳转按钮）；顶栏新增 `? 指南` 按钮随时重开。
- 统一 `<PrivacyExportModal>` 组件：所有花名册 / 转接表 / 志愿公示 / 积分报表导出均默认「脱敏公示版（身份证与手机号自动打码）」，切「全量报送版」需显式二次确认。
