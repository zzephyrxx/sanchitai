# 三尺台 · 项目章程与决策记录

> 学工个人（离线）工作台 · 暂名「三尺台」
> 启动时间：2026-11-18 23:13 · 工期目标：≥3 小时（三轮「实施→评审」迭代）
> 底座：soybean-admin v2.3.0（Vue3 + Vite8 + TS + Naive UI + UnoCSS + Pinia，MIT）

## 一、产品定位

面向高校学工人群（党支部书记 / 班长 / 社团负责人 / 辅导员）的个人离线工作台。
- **主视图 = 台历**：周 / 月工作安排（如「周三 14:00-16:00 支委会」），可编辑
- **多身份**：一人多身份，身份之间互不打通、数据隔离，v1 只做「党支部书记」
- **人员可视化**：教室/工位场景座位图，人头图标上见姓名（交互对标 classroom-workbench）
- **离线优先**：纯本地数据，默认浏览器可用，后续 Tauri v2 打包 Win/Mac

## 二、已确认的决策（2026-11-18 采访）

| 决策点 | 结论 | 备注 |
|---|---|---|
| 基座路线 | 工作台模板底座（soybean-admin） | super-productivity（Angular）作为数据模型/离线架构参考深度借鉴，不直接克隆改造 |
| 桌面形态 | Tauri v2（后续打包） | v1 以浏览器/PWA 为主，桌面打包在 v1 验收后接入 |
| 数据备份 | 本地库 + JSON 导入导出 + 自动快照 | 无账号体系，可选 WebDAV 不做（v1） |
| 书记场景 v1 | 三会一课排期、党员发展台账、党费台账、谈心谈话+材料库 | 四项全做 |

**修复过的底座级 bug**（含在交付说明中）：
