## 发现与已修复项

| 级别        | 位置                                       | 问题                                                                                                                                     | 修复措施                                                                                                                                                                                                |
| ----------- | ------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **P1 安全** | `src-tauri/src/local_server.rs`            | 本机 HTTP 微服务未限制请求头数量/行长，且 `POST /__sct_api/*` 未校验 `Host` 与自定义请求头，存在 DNS Rebinding / 跨站简单 POST CSRF 风险 | 新增 `Host` 严格回环校验、请求头行数/长度上限（64 行 / 8 KB）、并发连接数上限（32）、Origin 白名单 + 自定义 `X-Sct-Local: 1` 头强制预检校验，以及 `open_system_browser` 仅放行 `http://127.0.0.1:` 校验 |
| **P1 兼容** | `src-tauri/src/local_server.rs`            | Windows 下 `std::fs::rename` 覆盖已存在目标文件可能触发 `AlreadyExists` 失败                                                             | 抽离 `atomic_write_file()` 并在 `#[cfg(target_os = "windows")]` 下持锁先移除既有目标再 `rename`                                                                                                         |
| **P1 同步** | `src/utils/desktop-bridge.ts`              | 新开浏览器页若首次拉取超时可能反推空库覆盖桌面端同步文件；页面关闭时未立即刷盘防抖队列                                                   | 限定仅 `tauri-desktop` 端在首次拉取为空时执行种子推送；新增 `pagehide` 监听立即 flush 待推送队列                                                                                                        |
| **P2 交互** | `src/hooks/common/table-layout.ts`         | 列宽拖拽释放后的捕获阶段 click 拦截范围过大，可能吞掉 220ms 内对工具栏按钮的点击                                                         | 限定仅拦截落在 `<th>` 内的 click 事件，既 100% 阻断误触排序又不影响其他按钮                                                                                                                             |
| **P2 异步** | `src/views/ledger/members/index.vue`       | `handleMove` / `handleUndo` 使用 `.then()` 未捕获异常                                                                                    | 改为 `async/await` + `try/catch`                                                                                                                                                                        |
| **P2 样式** | `src/views/ledger/fees/index.vue`          | 党费矩阵 `table` 为 `width: 100%`，导致缩小列宽时浏览器自动拉伸                                                                          | 改为 `width: max-content; min-width: 100%; table-layout: fixed;`                                                                                                                                        |
| **P2 Rust** | `src-tauri/src/local_server.rs` / `lib.rs` | `cargo clippy -- -D warnings` 提示 `manual_flatten` 与 `redundant_closure`                                                               | 改用 `.flatten()` 与函数引用 `std::io::Error::other`，clippy 0 警告通过                                                                                                                                 |
